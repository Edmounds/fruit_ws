# C 区同停靠点连续作业

`actions.navigate_c_route` 在下发导航前检查是否可以复用当前停靠点。
只有以下条件全部满足时才跳过重复的 `FollowWaypoints`：

- 本次是带目标侧 Look 的作业路线，只有一个目标点和一个 yaw。
- 目标名称等于上次成功到达的航点名称。
- 上次导航已结束，结果明确为 `STATUS_SUCCEEDED`，且没有遗漏航点。
- 实时 TF 有效。缺失、过期或非有限位姿不能授权复用。
- 当前位置距目标不超过 `0.03 m`，朝向误差不超过 `0.042 rad`，包含边界。

满足条件后，只启动本次规划侧的 Look，再执行原有识别、采摘和失败推进。
日志包含 `C区复用当前停靠点`。任务表仍保留规划路线。
机械臂仍使用原有 planner 服务、实测静止检查和失败恢复。
二维码顺序、路线选择、全局导航容差和机械臂预设均不改变。

任一条件不满足时，继续原有导航流程，不新增重试。
收尾路线不带 Look，因此仍执行原有导航和最终朝向对齐。

底盘结束状态沿用已有导航结果，不是独立的硬件速度测量。
离线检查不代替现场停稳和机械臂扫掠空间验收。

源码修改后重新构建 `fruit_mission`，再重启 mission 节点。
不要通过修改 `install/` 中的副本部署。
