# 04. 设计访谈与决定记录

状态：访谈进行中，不实现控制代码。
原文档中尚未确认的建议属于草案，不等于用户已认可的决定。
每轮确认后同步更新架构和数据契约，最终再检查所有分支。

## 已确定的基础要求

- 三台关节电机：底座旋转、大臂、小臂。
- 两个舵机：腕部、夹爪。
- 对上层复用既有服务和话题，保留四轴姿态加独立夹爪语义。
- 解算、轨迹、到位判断与工序执行归上位机。
- 下位机执行当前设定值并周期回传实测，桥处理传输协议。
- 先完善文档，不实现或启用控制节点。

## 第一轮：已确认

| 议题 | 用户决定 | 设计影响 |
| --- | --- | --- |
| 关节电机控制模式 | 首版位置控制，力矩用于观测与保护 | 首版不启用 MIT/阻抗模式 |
| CLOSE 完成 | 首次确认接触即可返回完成 | 不以空夹爪闭合终点作为接触后的必要条件 |
| 持续抓紧 | 首次完成后持续给力，松动时继续闭合直至完全闭合 | 夹爪持续状态独立于机械臂服务占用 |
| 航点推进 | 每个航点配置是否停稳 | 拟增加 `wait_until_settled`，默认与强制条件待定 |
| 过短 duration_ms | 拒绝并说明约束原因 | 不自动延长用户指定时长 |
| 非硬件失败 | 空抓、超时等不能阻断后续操作 | 返回业务失败不建立硬件故障锁 |
| 硬件故障 | 可以报错，必须明确类别 | 不把普通业务失败归成硬件故障 |
| 启动行为 | 保持当前位置，显式请求 Home | 不自动回零或执行预设 |

## 第二轮：已确认

| 议题 | 用户决定 | 设计影响 |
| --- | --- | --- |
| 当前型号 | 用户表示可以提供，但本轮未填写具体型号 | 仍不得宣称某型号能力已确认 |
| HOLD | 保留当前持续抓紧策略 | mission 的 HOLD 驻留不取消追紧 |
| 航点默认值 | `wait_until_settled` 默认 true | 无夹爪中间点可 false，夹爪和最终点强制停稳 |
| 未到位结束 | 有限等待后返回非硬件失败 | 独立计时、释放 service 占用，实测停稳后放行后续 |
| 完全闭合但无接触 | 夹爪动作完成就返回成功 | 不等于证明抓到果实，不自动跳过 Store |
| 普通 STOP | 冻结有效夹爪位置并保持 | 不主动追紧，也不自动松爪 |

## 第三轮：已确认

| 议题 | 用户决定 | 设计影响 |
| --- | --- | --- |
| 型号 | 暂时没有型号，明确保留待核实 | 不阻塞行为访谈，不假定厂商能力 |
| 等待窗口 | 机械臂到位与夹爪动作分别默认 2 秒，可配置 | 两个独立窗口，dwell 另计，参数待台架验证 |
| STOP 后追紧恢复 | 只有再次 CLOSE 才恢复 | HOLD 和普通机械臂运动保留冻结状态 |
| 硬件故障恢复 | 显式解除故障锁 | 故障原因消失不自动放行 |
| 重叠业务请求 | 当前未完成时拒绝新请求 | 不排队、不抢占，jog 的目标累积留在客户端 |

## 第四轮：已确认，覆盖第三轮恢复策略

| 议题 | 用户决定 | 设计影响 |
| --- | --- | --- |
| 持续抓紧 | 完全闭合位置目标加经验证的夹紧限制 | 不要求恒力，能力与安全范围需型号和测量验证 |
| 接触证据 | 位置、低速度加负载或电流 | 不以单独位置停滞作为首版默认接触证据 |
| 硬件恢复 | 条件恢复后自动解除软件锁 | 覆盖第三轮显式解锁选择，不新增 clear_fault |
| 软件停止 | 所有软件急停换成普通 STOP | emergency_stop 保留端点但成为 STOP 别名，无独立人工急停解锁 |
| 过渡点 | 首版只取消等待，不做轨迹混合 | 每段参考首末速度仍为零 |

软件停止统一不等于绕过驱动器的本地保护。
驱动器过流、过温等事实仍会阻止运动，原因消失且恢复条件满足后才放行新请求。

## 第五轮：当前待决分支

1. 舵机无负载或电流读数时是否禁用接触提前完成。
2. 恢复条件需要连续稳定多久。
3. 控制与反馈的初始目标频率。
4. 使能由上位机自动完成，还是需要显式操作。
5. 首版软件语言和数学模块复用方式。

## 后续依赖分支

- 根据舵机能力确定持续抓紧方式、力或电流上限及接触检测依据。
- 根据推进策略确定过渡点的跟踪误差与参考连续性。
- 根据失败结果确定 service message、兼容状态与 mission 跳过行为。
- 确定硬件故障、失联、MCU 重启和恢复的状态边界。
- 确定使能入口、配置所有权与单一控制源。
- 根据实际链路能力确定下发频率、各轴反馈频率与新鲜度预算。
- 确定容差标定、日志、台架验收及部署迁移顺序。

## 必须区分的事实

位置模式维持闭合目标可以产生持续夹紧作用，但不自动保证恒定夹持力。
是否支持电流限制、负载限制或力矩模式，需要对应舵机型号证据。
第一次接触确认、持续抓紧、水果实际抓牢是三个不同结果。
普通业务失败不锁死后续服务，但失联或未知运动仍必须处理安全停机。
