# 05. DM / FTS 执行器参数与换算边界

本文件记录用户补充的实际参数及需要标定的参数，不实现任何控制代码。
具体型号暂未提供，不能据此确定厂商寄存器、力矩单位或所有控制模式。

## 1. 已提供的数据

| 执行器 | 已知参数 | 上位机职责 |
| --- | --- | --- |
| 三台 DM | 位置、速度及电流或力矩反馈 | 电机零位、方向、机械关节与电机轴关系、肩肘耦合补偿 |
| FTS ID1，腕部 | 零位 2047，原生位置范围 0..4095，正方向 | 将腕部目标换成原生位置刻度，反算实测腕部角 |
| FTS ID2，夹爪 | 张开 400，闭合 0 | 生成开合目标、速度、加速度和电流参数 |
| 夹取动作 | 电流抓取判断，接触后再闭合 50 原生单位 | 接触判据、一次追加闭合、持续追紧及覆盖条件 |
| 所有执行器 | 位置、速度、电流或力矩、在线、故障 | 样本有效性、完成判断及恢复条件 |

ID1 原生位置增大代表配置中的正方向。
它对应模型腕角的正号还须结合安装与现有映射核对，不能再次叠加方向翻转。
0..4095 是原生计数范围，尚未确认一个计数对应多少角度。
不能仅凭该范围就把 4095 或 4096 当成一整圈换算常数。

ID2 的闭合方向是原生位置递减，张开方向是原生位置递增。
追加闭合 50 单位对应位置减 50，不是增加 50，也不是 50 度。
例如在 180 处确认接触，则追加闭合目标为 130。
若在 30 处接触，按闭合下限限幅后追加目标为 0，不能发送负计数。

## 2. 三台 DM 换算参数

每台 DM 明确以下配置，并记录标定参考姿态：

| 参数 | 单位 / 说明 |
| --- | --- |
| 电机 ID | 厂商总线 ID，不等于模型关节编号 |
| `motor_zero_rad` | 在指定参考机械姿态的电机轴位置，rad |
| `direction` | +1 或 -1，定义机械关节正运动与电机轴正运动的关系 |
| `motor_to_joint_ratio` | 传动比，必须注明轴角 / 关节角或其倒数，不能混用 |
| 参考机械关节角 | 模型关节 rad，避免只写不明含义的“零位” |
| 肩肘耦合系数及参考 | 大臂变化对小臂电机目标的补偿，正负号需实测 |
| 位置范围 | 电机轴允许范围与机械关节范围分别记录 |
| 速度、加速度范围 | 按电机轴量纲配置，与机械关节导数正确换算 |

全部运动学换算与传动耦合由上位机完成，MCU 不重新补偿肩肘关系。
现有 JointTransformer 的 Q3 已包含 `q2_algo + q3_algo`。
如果传动系数也写成包含大臂项的完整关系，不能把该项重复加入两次。
必须明确某个参数表示完整耦合还是已有映射之后的残差修正。

推荐以完整的双向映射表或关系式作为唯一权威定义。
先以实测验证现有 Q3 绝对小臂硬件角关系，再决定需要扩展的参数。
如果实机电机轴读数与旧 API 硬件角不一致，应先明确适配边界。
不能为了保持旧 YAML 数字不变而向 mission 发布虚假的原始硬件角。
标定改变后所有算法、控制台及 mission 校验共同更新，不保留两套映射。

## 3. DM 控制参数

首版采用位置控制，下发每台 DM 的当前电机轴目标位置和运行速度参数。
运行速度到底是有符号目标速度还是非负速度上限，需要对应型号确认。
电机内部伺服环保留，上位机不经串口执行高速电流环。

用户补充的 MIT 参数为目标速度、Kp、Kd 和前馈力矩。
这些参数属于厂商能力说明，首版的位置控制决定没有改变。
以后确需 MIT 时再协调数据版本和验证量纲，本次不加入首版控制流程。

## 4. FTS 控制参数

两台 FTS 均记录原生位置、速度、加速度和电流参数的有效范围。
首版 MCU 接收上位机算好的原生位置刻度，不把模型角再次换算成舵机刻度。
MCU 只做厂商寄存器单位转换和基础保护，不应用模型零位或传动补偿。

| 参数 | ID1 腕部 | ID2 夹爪 |
| --- | --- | --- |
| 原生位置 | 0..4095，零位 2047 | 业务张开 400，业务闭合 0 |
| 位置正方向 | 已提供正方向，需校对模型映射 | 增大张开，减小闭合 |
| 速度 / 加速度 | 型号单位与上限待核实 | 型号单位与上限待核实 |
| 电流参数 | 是否使用及有效范围待核实 | 抓取电流判据与控制电流语义待确认 |
| 原生反馈 | 位置、速度、电流或力矩、在线、故障 | 同左，并支持接触判断 |

ID2 的 0..400 是已给出的业务开合区间，不宣称它等于设备完整物理范围。
ID1 的 0..4095 也不是允许整圈运动的机械安全范围。
机械安全限位需要独立标定，不能用寄存器范围替代。

原生速度与加速度的寄存器编码必须有明确量纲。
未知时标待核实，不把编码值直接标为 rad/s 或 A。
“目标电流”究竟表示电流模式目标还是位置模式电流限制，正在最后一轮确认。

## 5. 夹爪动作与追加 50 单位

初次抓取采用位置、低速度及有效电流或力矩证据共同判断接触。
电流阈值、低速阈值和稳定窗口需标定，不能由 50 单位推出夹持力。
首次确认接触可以返回 CLOSE 成功，持续夹紧在同一节点中继续运行。

追加闭合目标按 `max(0, contact_position_count - 50)` 计算。
只在首次有效接触事件计算一次，不能每个反馈周期再次减 50。
初次完全闭合且没有接触证据也返回动作成功，沿用已确认的空闭合策略。
此时目标保持 0，不执行越界的额外闭合。

追加 50 的阶段如何转入持续追紧到 0，正在最后一轮确认。
OPEN 覆盖全部追紧状态，目标为 400。
HOLD 保留当前策略，普通 STOP 冻结有效实测位置。
STOP 后只有再次明确 CLOSE 才恢复追紧，不重放旧追加闭合事件。

## 6. 反馈和时序

DM 回传实际电机轴位置和速度，FTS 回传实际原生位置、速度。
上位机先反算统一硬件角，再调用共享映射与 FK，生成原 ArmTelemetry。
原生数据与换算数据不得在同一字段混用。
电流或力矩反馈带有效标志、样本编号、年龄、在线与故障状态。

首版命令帧与反馈帧目标频率均为 20 Hz。
下位机应用同一组当前设定值，并反馈整组应用编号及各轴实测样本。
厂商总线实际应用时刻不同，需测量各轴同步偏差，不能宣称同时写入。
通信超时、停止、重启及恢复按数据契约处理，不交给下位机业务到位判断。
封装、CRC、ACK 和重发仍由通信桥负责。
