## 一、机械臂物理连杆模型与几何拓扑

采摘机械臂具有 **4 个转动自由度 (4-DOF)**，构型为标准的 **偏航(Yaw) + 肩部俯仰(Pitch) + 肘部俯仰(Pitch) + 腕部俯仰(Pitch)**。

```text
       Z (天顶)
       ▲
       │                  [肘关节 P2]
       │                  ●──────────────● [腕关节 P3] ───● [伸出段末端 P4]
       │                 /  (小臂连杆 a3)    (腕部连杆 a4)
       │                /                                 │ 固定局部 Z 偏移
       │               /                                  ● [真实抓取点 TCP]
       │              / (大臂连杆 a2)
       │              ● [肩关节 P1]
       │              │
       │              │ (基座高度 d1)
       │              │
  ─────┴──────────────● [底盘回转中心 P0] ────────────────► X (正前方)
```

### 连杆尺寸符号定义（配置于 `config/arm_presets.yaml`）
- **`d1` (基座高度)**：底盘安装基准面到肩部俯仰轴轴心的高度差；
- **`a2` (大臂长度)**：肩部旋转轴中心到肘部旋转轴中心的距离；
- **`a3` (小臂长度)**：肘部旋转轴中心到腕部俯仰轴中心的距离；
- **`a4` (末端伸出长度)**：腕部旋转轴沿末端局部 X 方向到伸出段末端的长度，不是腕轴到真实抓取点的斜线长度。
- **`tool_z_offset_m`**：伸出段末端到真实夹爪抓取点 TCP 的固定局部 Z 偏移，下方为负，随腕部俯仰和底座偏航旋转。当前为 `-0.03 m`，在 YAML 中调参，不是世界 Z 平移，也不增加运动自由度。

上述几何参数在启动时全部由 `config/arm_presets.yaml` 提供。四个连杆尺寸必须有限且为正，局部 Z 偏移必须是有限数，可为零或正负值；算法内部不设几何默认值。

## 二、正向运动学 (FK) 数学推导

正运动学（Forward Kinematics, FK）负责在已知各关节转角 $(q_1, q_2, q_3, q_4)$ 的前提下，计算末端作用点在空间中的坐标 $(X, Y, Z)$ 及空间俯仰角 $\text{pitch}$。

### 1. 空间极坐标平面投影分解
因为关节 $q_1$ 纯粹控制整条臂在水平面 $(X, Y)$ 内绕 $Z$ 轴回转，臂身的其余三个俯仰关节（肩、肘、腕）均在同一个垂直回转平面内运动。因此，我们将 3D 问题分解为：
- 水平回转角：$q_1$；
- 垂直运动平面：以水平伸出径向距离 $r$ 为横轴、坚直高度 $z$ 为纵轴的 2D $(r, z)$ 平面。

### 2. 算法理论基准下的逐级连杆递推
算法理论空间定义：**各关节角度为 0 时，机械臂全部连杆沿 X 轴水平伸直**。
设回转底座中心为原点 $P_0 = (0, 0, 0)$。

#### ① 肩关节中心 $P_1$：
$$P_1 = (0, 0, d_1)$$

#### ② 肘关节中心 $P_2$：
大臂相对水平面的俯仰角为 $\theta_2 = q_2$：
- 径向投影距离：$r_2 = a_2 \cdot \cos(q_2)$
- 坚直高度：$z_2 = d_1 + a_2 \cdot \sin(q_2)$
投影到 3D 笛卡尔坐标系：
$$P_2 = \big(r_2 \cdot \cos(q_1), \; r_2 \cdot \sin(q_1), \; z_2\big)$$

#### ③ 腕关节中心 $P_3$：
小臂在空中的绝对俯仰倾角为大臂角度与小臂相对夹角的代数和：$\theta_{23} = q_2 + q_3$：
- 径向投影距离：$r_3 = r_2 + a_3 \cdot \cos(q_2 + q_3)$
- 坚直高度：$z_3 = z_2 + a_3 \cdot \sin(q_2 + q_3)$
投影到 3D 笛卡尔坐标系：
$$P_3 = \big(r_3 \cdot \cos(q_1), \; r_3 \cdot \sin(q_1), \; z_3\big)$$

#### ④ 伸出段末端 $P_4$ 与末端空间俯仰角 $\text{pitch}$：
末端伸出段 a4 的总俯仰角为三个俯仰关节转角之和：
$$\text{pitch} = q_2 + q_3 + q_4$$
- 径向投影距离：$r_4 = r_3 + a_4 \cdot \cos(\text{pitch})$
- 坚直高度：$z_4 = z_3 + a_4 \cdot \sin(\text{pitch})$
#### ⑤ 真实夹爪抓取点 TCP：
令 $b=\text{tool\_z\_offset\_m}$，固定偏移沿末端局部 Z 轴旋转：
$$r_{TCP}=r_4-b\sin(\text{pitch}), \qquad z_{TCP}=z_4+b\cos(\text{pitch})$$
$$X=r_{TCP}\cos(q_1), \quad Y=r_{TCP}\sin(q_1), \quad Z=z_{TCP}$$

FK 的 `end_effector` 返回 TCP 的 `(x,y,z,pitch)`；`points` 按顺序返回 `P0/P1/P2/P3/P4/TCP`，包含固定下偏段。`pitch` 仍然描述 a4 段，**不描述腕轴到 TCP 的斜线**。`pitch=0°` 时 a4 水平，TCP 比腕轴低 3 cm；不会为斜线附加角度修正。

## 三、逆向运动学 (IK) 几何解析推导

逆运动学（Inverse Kinematics, IK）负责根据真实抓取点 TCP 的目标 $(X, Y, Z)$ 及 a4 段期望俯仰角 $\text{pitch}$，反算出 4 个关节理论转角 $(q_1, q_2, q_3, q_4)$。直接笛卡尔请求和笛卡尔预设共用此模型，不再对输入坐标额外平移。任务层（如 B 区根据目标基座高度划分 Up/Down 层级并选择抓取 pitch、偏置与 Store 预设）属于任务客户端策略，直接通过 `MoveArmCartesian` 等标准接口下发，不改变底层运动学解算模型。

### 1. 求解基座旋转偏航角 $q_1$
由于机械臂安装于小车前进方向，底座直接朝向目标点在底盘水平面上的投影：
$$q_1 = \text{atan2}(Y, X)$$
末端在水平面的总径向投影跨度为：
$$r = \sqrt{X^2 + Y^2}$$

### 2. 末端隔离，逆推腕部中心 $P_3$ 在 $(r, z)$ 平面内的位置
已知 TCP 位置为 $(r, Z)$，伸出长度为 $a_4$，局部 Z 偏移为 $b$。反向扣除这两段刚性结构，得到腕关节中心坐标（$z_w$ 相对肩轴）：
$$r_w = r - a_4 \cos(\text{pitch}) + b\sin(\text{pitch})$$
$$z_w = (Z - d_1) - a_4 \sin(\text{pitch}) - b\cos(\text{pitch})$$

水平时 $b=-0.03m$，腕轴比请求的 TCP 高 3 cm；倾斜时按姿态旋转补偿。腕部角仍为 $q_4=\text{pitch}-(q_2+q_3)$，与关节零位标定无关。

### 3. 工作空间物理可达性检查
计算肩关节 $P_1(0, d_1)$ 到腕关节 $P_3(r_w, z_w + d_1)$ 的直线连线长度 $d$：
$$d^2 = r_w^2 + z_w^2, \quad d = \sqrt{d^2}$$

大臂 $a_2$、小臂 $a_3$ 与连线 $d$ 必须能构成一个封闭的三角形。因此必须满足三角形两边之和大于第三边、两边之差小于第三边：
$$|a_2 - a_3| \le d \le (a_2 + a_3)$$
若不满足此条件，目标点超出物理可达工作空间，逆解直接报错返回。

### 4. 三角形内角余弦定理求解
设肩-腕连线在垂直平面内的方位仰角为 $\alpha$：
$$\alpha = \text{atan2}(z_w, r_w)$$

在连杆三角形 $\triangle P_1 P_2 P_3$ 中：
- 肩关节内角 $\beta$（大臂 $a_2$ 与肩-腕连线 $d$ 的夹角）：
  $$\cos\beta = \frac{a_2^2 + d^2 - a_3^2}{2 \cdot a_2 \cdot d} \implies \beta = \arccos\big(\text{clamp}(\cos\beta, -1.0, 1.0)\big)$$
- 肘关节内角 $\gamma$（大臂 $a_2$ 与小臂 $a_3$ 的夹角）：
  $$\cos\gamma = \frac{a_2^2 + a_3^2 - d^2}{2 \cdot a_2 \cdot a_3} \implies \gamma = \arccos\big(\text{clamp}(\cos\gamma, -1.0, 1.0)\big)$$

## 四、高位构型 (Elbow-Up) 约束与奇异点规避

对于同一个空间目标点 $(X, Y, Z)$，机械臂在几何上存在两个对称解：

```text
        【高位构型 (Elbow-Up) - 选用】              【低位构型 (Elbow-Down) - 禁用】
             P2 (肘部高高抬起)
            ●───────● P3                                  P1
           /         \                                    ●
          /           ● P4                               / \
         /                                              /   \
        ● P1                                           /     ● P3 ──● P4
                                                      ● P2 (肘部下沉极易撞底盘)
```

1. **低位构型 (Elbow-Down)**：
   $$q_2 = \alpha - \beta, \quad q_3 = \pi - \gamma$$
   此构型下肘部向下弯曲悬垂，极易与车身顶板、底盘电池仓及激光雷达发生结构干涉。
2. **高位构型 (Elbow-Up，强制锁定)**：
   $$q_2 = \alpha + \beta$$
   $$q_3 = -(\pi - \gamma)$$
   大臂向前上方抬起，小臂自上而下俯探伸入果树，具有最佳的采摘视野和避障能力。
3. **腕关节角闭环解算**：
   $$q_4 = \text{pitch} - (q_2 + q_3)$$

## 五、关节坐标系偏置映射数学模型 (JointTransformer)

### 1. 为什么需要坐标映射解耦？
- **算法理论空间 ($q_{\text{algo}}$)**：伸直为 0°，便于几何三角公式推导；
- **物理硬件空间 ($q_{\text{hardware}}$)**：电机反馈/命令角度；与连杆实际零位之间的偏置和方向由 `arm_presets.yaml` 中的 `joint_mapping` 给出。

### 2. 双向线性映射关系
Q1、Q2、Q4 使用各自独立的角度映射：
$$q_{i,\text{hardware}} = \text{direction}_i \cdot q_{i,\text{algo}} + \text{offset}_i \quad (i=1,2,4)$$

小臂通过同步带传动，Q3 电机角表示小臂相对水平面的绝对俯仰角，而算法中的 $q_3$ 仍表示小臂相对大臂的夹角。因此 Q3 必须使用大臂角参与双向换算：
$$q_{3,\text{hardware}} = \text{direction}_3 \cdot (q_{2,\text{algo}} + q_{3,\text{algo}}) + \text{offset}_3$$
$$q_{3,\text{algo}} = \frac{q_{3,\text{hardware}} - \text{offset}_3}{\text{direction}_3} - q_{2,\text{algo}}$$

### 3. 各关节偏置推导详解
- **Q1（偏航基座）**：正前为 0°，左正右负 $\implies \text{offset} = 0.0^\circ, \text{direction} = +1.0$；
- **Q2（大臂）**：
  - 理论伸直时 $q_{2,\text{algo}} = 0^\circ$（水平）；
  - 硬件物理 0° 是竖直朝天，对应理论角 $q_{2,\text{algo}} = +90^\circ$；
  - 理想安装下偏置为 $-90^\circ$；实际补偿值由 YAML 标定，当前为 $-89^\circ$；
  - 向上抬为正，向前下方俯低为负，大臂俯下到接近水平时对应 $-87^\circ \sim -90^\circ$；
- **Q3（小臂）**：
  - 小臂水平朝前时，绝对倾角 $q_2 + q_3 = 0^\circ$，硬件角也为 $0^\circ$；
- 已确认小臂水平时原始反馈约为 $0^\circ$，且大臂单独转动时该反馈不变；计算时由映射器统一处理源码 YAML 的标定偏置，当前值为 $-13^\circ$，不从 YAML 注释或旧文档取值；
  - 小臂相对水平面向上为正，向下为负；
- **Q4（腕部）**：
  - 电机安装在小臂上，算法将 Q4 定义为末端相对小臂的角度。当前 YAML 映射为 $\mathbf{offset = -5.0^\circ, direction = +1.0}$；当小臂不水平时，Q4 的硬件角为零并不代表末端水平。

---

反馈遥测还提供模型角速度：$\dot q_2=\dot h_2/direction_2$，$\dot q_3=\dot h_3/direction_3-\dot q_2$，Q1/Q4 各自除以 direction。常量 offset 求导为零，不能对速度套用角度偏置。此转换复用 `JointTransformer.hardware_velocity_to_algo`，非有限速度不替成零。

## 六、五次多项式平滑轨迹插值原理 (TrajectoryPlanner)

机械臂在加减速过程中，如果加速度突变，会对机械减速器和连杆产生剧烈冲击（Jerk）。本包采用**归一化五次多项式 (Quintic Polynomial / S-Curve)** 进行离散时间插值。

### 1. 归一化插值曲线
设运动总时间为 $T$，定义归一化时间参数 $s$：
$$s = \frac{t}{T}, \quad s \in [0, 1]$$

平滑标量函数 $S(s)$ 表达式为：
$$S(s) = 10 \cdot s^3 - 15 \cdot s^4 + 6 \cdot s^5$$

### 2. 速度与加速度边界证明
- **位置边界**：
  $$S(0) = 0, \quad S(1) = 1$$
- **一阶导数（速度因子）**：
  $$\dot{S}(s) = 30 \cdot s^2 - 60 \cdot s^3 + 30 \cdot s^4 = 30 \cdot s^2 (1 - s)^2$$
  当 $s = 0$ 时，$\dot{S}(0) = 0$；当 $s = 1$ 时，$\dot{S}(1) = 0$。**起步与停车速度严格为 0**。
- **二阶导数（加速度因子）**：
  $$\ddot{S}(s) = 60 \cdot s - 180 \cdot s^2 + 120 \cdot s^3 = 60 \cdot s (1 - s) (1 - 2s)$$
  当 $s = 0$ 时，$\ddot{S}(0) = 0$；当 $s = 1$ 时，$\ddot{S}(1) = 0$。**起步与停车加速度严格为 0，杜绝机构抖动**。

### 3. 轨迹航路点生成
对于任意关节，从起点角度 $q_{\text{start}}$ 到目标角度 $q_{\text{target}}$：
$$q(t) = q_{\text{start}} + S\left(\frac{t}{T}\right) \cdot (q_{\text{target}} - q_{\text{start}})$$

按 YAML 的 `planning.interpolation_step_ms` 采样生成包含时间戳与 4 关节弧度值的 `TrajectoryPoint` 序列；当前配置为 200ms。

每个 `TrajectoryPoint` 还带有 `is_via_point`：轨迹第 0 个实测起点和最终目标点默认为精确点（`0`），自动生成的中间插值点为途经点（`1`）。预设 waypoint 可显式设置该标记；它只供下位机选择到位容差，不改变上位机的插值、IK、映射或限位检查。

`duration_ms` 描述计划轨迹时间，不是服务执行期限。planner 最多等待 10 秒，期间等待下位机
报告完成/失败或主动停止；此等待期限不影响插补、几何、标定或预设航点，反馈新鲜度与限位
校验仍保留。修改代码后构建并重启 planner 及 mission；仅 reload presets 不会更新执行策略。

## 七、解算模式选型与数学原理对比（PTP 关节过渡 vs LIN 笛卡尔直线插补）

在工业与农业机器人作业中，单一的运动规划方式无法同时满足“高速避障大范围移动”与“狭窄缝隙毫米级精准采摘”的双重诉求。因此，系统必须提供**两种完全解耦的末端解算模式**供调用者按需选择：

```text
                                  【目标位姿输入】(X, Y, Z, pitch)
                                                │
                     ┌──────────────────────────┴──────────────────────────┐
                     ▼                                                     ▼
        【模式 A: 关节平滑过渡 (PTP)】                         【模式 B: 笛卡尔严格直线 (LIN)】
        (Point-to-Point / 快速空间转移)                       (Cartesian Linear / 高精度采摘刺入)
                     │                                                     │
        1. 仅对目标终点调用 1 次 IK                            1. 通过 FK 求解实车当前起点 (X0, Y0, Z0)
           求得目标关节角 Q_goal                               2. 在 3D 空间直线按时间切分 N 个采样点:
        2. 各关节按五次多项式同步插值:                             P(t) = P0 + S(t/T) * (P1 - P0)
           q(t) = q_start + S(s) * (Q_goal - q_start)         3. 对沿途每一个点逐一求解 1 次 IK (共 N 次)
        3. 末端在三维空间中呈平滑自然弧线                      4. 末端在三维空间中呈严格几何直线
                     │                                                     │
                     └──────────────────────────┬──────────────────────────┘
                                                ▼
                                    【生成统一 TrajectoryPoint 序列】
```

### 1. 模式 A：关节平滑过渡 (PTP / Point-to-Point)
- **数学本质**：规划发生在**关节空间（Joint Space）**。
- **算法流程**：
  1. 仅对最终的目标点 $(X_{\text{goal}}, Y_{\text{goal}}, Z_{\text{goal}}, \text{pitch}_{\text{goal}})$ 求解一次逆运动学，得到目标关节角度 $\mathbf{Q}_{\text{goal}}$；
  2. 以当前实机角度 $\mathbf{Q}_{\text{current}}$ 为起点，在关节空间进行五次多项式平滑插值：
     $$\mathbf{q}(t) = \mathbf{Q}_{\text{current}} + S\left(\frac{t}{T}\right) \cdot (\mathbf{Q}_{\text{goal}} - \mathbf{Q}_{\text{current}})$$
  3. 各关节独立单调平滑转动，末端在三维空间中的轨迹是连杆转动自然形成的**平滑弧线（Arc）**。
- **优点**：
  - **计算极轻量**：整条轨迹仅需计算一次 IK，耗时 $< 10\mu s$；
  - **鲁棒性极高**：只要起点和终点合法，中间绝不会因为“途径不可达空洞”而中途报错中断；
  - **关节负载均匀**：各电机运动速度连续无突变，机械寿命长。
- **适用场景**：
  - 空旷空间的大范围移臂（如从树冠收回到底盘上方、在不同果实之间快速转移）；
  - 不需要严格限制末端空中路径的普通位姿调整。

### 2. 模式 B：笛卡尔严格直线插补 (LIN / Cartesian Linear Path)
- **数学本质**：规划发生在**末端笛卡尔操作空间（Task Space）**。
- **算法流程**：
  1. 调用正运动学 (FK)，精确获取当前实车末端起点空间坐标 $P_0(X_0, Y_0, Z_0, \text{pitch}_0)$；
2. 根据目标空间坐标 $P_1(X_1, Y_1, Z_1, \text{pitch}_1)$、运动时间 $T$ 与源码 YAML 的 `planning.interpolation_step_ms` 生成离散航路点，包含起终点；采样间隔不是固定 50ms，也不是下位机状态回报周期；
  3. 沿空间直线利用五次多项式标量因子插补出连续位姿序列：
     $$\mathbf{P}(t_i) = P_0 + S\left(\frac{t_i}{T}\right) \cdot (P_1 - P_0), \quad i \in [1, N]$$
  4. **沿途逐点求解逆解**：对序列中的每一个空间点 $\mathbf{P}(t_i)$，逐一调用一次 `kinematics.inverse_kinematics()`，解出对应的关节角度 $\mathbf{q}_i$；
  5. 校验沿途每个点的关节软限位，若全部合法则打包输出。
- **优点**：
  - **末端轨迹严格走直线**：末端执行器在空中始终严格贴合直线几何路径，无任何侧向漂移和上下晃动；
  - **高精度空间避障**：可以精确保证机械臂不碰到果实周围密集的硬质树枝或铁丝网。
- **限制与注意点**：
- **全路径可达性约束**：任一离散点换算后的腕部中心超出 $|a_2-a_3|$ 到 $a_2+a_3$ 的肩轴距离范围，或关节映射后超限，规划均失败；不能以旧固定基座半径判断全部构型；
- **计算量提升**：逐离散点执行解析 IK，次数由时长与插值间隔决定；实际耗时须实测，不用理论复杂度承诺固定毫秒数。
- **适用场景**：
  - **采摘探入**：末端夹爪对准果实后，沿水平直线平直刺入果实分支 5~15cm；
  - **脱柄提拉**：夹紧果实后，末端沿垂直正上方直线拔起 6cm，防止斜拉扯断树枝；
  - **入仓放置**：将果实直线放进果篮口，杜绝弧线运动碰擦果篮壁。

### 3. 两种解算模式选型决策对比表

| 对比维度 | 模式 A：关节平滑过渡 (PTP) | 模式 B：笛卡尔严格直线 (LIN) |
| :--- | :--- | :--- |
| **插补所在空间** | 关节角度空间 (Joint Space) | 末端笛卡尔空间 (Task Space) |
| **末端几何轨迹** | 自然平滑空间弧线 (Arc) | **严格三维几何直线 (Straight Line)** |
| **逆解调用频次** | 仅终点求解 1 次 | **按配置的插值间隔逐点求解** |
| **计算时间** | 须实测 | 随点数变化，须实测 |
| **可达性检查** | 终点 IK、起点反馈和硬件限位均须有效 | 沿途离散点 IK 与限位均须有效 |
| **最佳业务场景** | 复位 Home、避障收纳 Retract、大范围转移 | **对准果实水平刺入、垂直拔果脱柄、狭窄缝隙避障** |
